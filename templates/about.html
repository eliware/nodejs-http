About this service

Node.js packages from Eliware

We package official precompiled Node.js Linux x64 releases for CentOS Stream 10 EPEL.

What this service does

This site serves signed RPMs, repository metadata, release records, validation results, provenance, and published container images.

The HTTP application reads the published repository as read-only content. The separate local conductor packages and signs the official Node.js archive.

Supported target

Stable Node.js 26 packages target CentOS Stream 10 EPEL on x86_64 systems. Install and update them with DNF or YUM.

Release information

Review the release catalog, package provenance, and validation record.
