Questions

Frequently asked questions

Which systems does this repository support?

It provides stable x86_64 RPMs for CentOS Stream 10 EPEL.

Does the RPM compile Node.js?

No. It packages the official precompiled Node.js Linux x64 archive.

How do I update Node.js?

Run sudo dnf update or sudo yum update. DNF keeps global npm tools outside RPM-managed files.

Does publishing an HTTP image deploy the service?

No. Image publication and application deployment are separate operations.
