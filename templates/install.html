Update Node.js

Keep the Eliware repository file installed. DNF and YUM will show newer stable RPMs when the conductor publishes them.

Run sudo dnf update eliware-node26 or sudo yum update eliware-node26.

Global tools and local links

The RPM keeps npm global packages outside its managed runtime files. The profile script adds the global command directory to PATH.

Use npm install --global package-name to add a command. Use npm link to link a local package.
