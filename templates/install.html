Eliware Node.js 26

Install Node.js 26 on CentOS Stream 10

Download the repository configuration, then install the signed RPM with DNF.

sudo dnf config-manager --add-repo https://nodejs.eliware.org/nodejs26.repo
sudo dnf install eliware-nodejs26
sudo yum -y update

The RPM installs versioned commands named node26, npm26, and npx26.

The RPM includes npm 12 or later and keeps global tools outside RPM-managed files.

Use npm26 -g install npm@latest to update npm. Use npm26 link to link a local package.
